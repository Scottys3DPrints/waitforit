Privacy Policy

Wait For It Uploader · last updated 29 September 2026

This policy covers Wait For It Uploader, a private tool that uploads videos to the Wait For It Clips YouTube channel. It is operated by the owner of that channel ("we") for our own use only.

YouTube API Services

Wait For It Uploader uses the YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data we access

  • The basic details of our own YouTube channel (channel ID and name), to confirm which channel we are uploading to.
  • Upload and processing status of the videos we upload.

We only use the permissions to upload videos to our own channel and to read that channel's details. We do not access, collect or store any data about other YouTube users, viewers, commenters or subscribers.

How we use and store it

The OAuth access token and the list of videos we have uploaded are stored locally on the channel owner's computer. This data is used only to run uploads and to avoid uploading the same clip twice. It is not stored on any server of ours.

Sharing

We do not sell, share or disclose any data obtained through the YouTube API Services to third parties. No advertising, analytics or tracking tools are used by the tool or by this website. This site uses no cookies.

Retention and deletion

Stored data is kept only as long as needed to run the channel and is refreshed at least every 30 days. You can revoke Wait For It Uploader's access at any time through the Google security settings page; the stored token then stops working and we delete it.
